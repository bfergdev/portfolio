# Game Developer Portfolio

A stunning, modern portfolio website for game developers built with React, Vite, TailwindCSS, and Framer Motion.

## Features

- 🎮 **Gaming-Inspired Design** - Sleek, futuristic UI with neon accents and smooth animations
- ✨ **Interactive Particle Background** - Dynamic canvas-based particle system
- 🎨 **Smooth Animations** - Powered by Framer Motion for buttery-smooth transitions
- 📱 **Fully Responsive** - Looks great on all devices from mobile to desktop
- 🚀 **Performance Optimized** - Fast loading and smooth 60fps animations
- 🎯 **Modern Stack** - React 18, Vite, TailwindCSS, Lucide Icons

## Sections

1. **Hero** - Eye-catching introduction with call-to-action buttons
2. **About** - Showcase your experience and achievements
3. **Projects** - Display your game portfolio with images and tags
4. **Skills** - Animated skill bars showing your expertise
5. **Contact** - Contact form and social media links

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Customization

### Update Personal Information

Edit the following files to customize with your information:

- `src/components/Hero.jsx` - Update name, title, and description
- `src/components/About.jsx` - Add your stats and features
- `src/components/Projects.jsx` - Replace with your actual projects
- `src/components/Skills.jsx` - Update with your skills and proficiency levels
- `src/components/Contact.jsx` - Add your contact information and social links

### Change Colors

Edit `tailwind.config.js` to customize the color scheme:

```js
colors: {
  primary: { ... },  // Main accent color
  accent: { ... },   // Secondary accent color
}
```

### Add Your Images

Replace the placeholder images in `src/components/Projects.jsx` with your actual game screenshots.

## Technologies Used
